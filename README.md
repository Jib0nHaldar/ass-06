# 🏋️ FitLog

A modern workout and fitness planning web application that helps users explore workouts, view exercise details, and build a personalized daily workout plan.

## 🚀 Technologies Used

* **Next.js** — React framework for building the application
* **React** — Component-based UI development
* **TypeScript** — Type-safe JavaScript development
* **Tailwind CSS** — Responsive and modern UI styling
* **REST API** — Fetching workout and fitness data
* **Local Storage** — Saving the user's workout plan locally

## ✨ Key Features

### 1. 🏃 Workout Library

Browse a collection of workouts and explore different exercises with useful information such as equipment, duration, calories, and ratings.

### 2. 📋 Workout Details

View detailed information about individual workouts through dedicated workout detail pages.

### 3. ➕ Personalized My Plan

Add workouts to your personal daily plan and keep track of the exercises you want to complete.

### 4. 📊 Live Workout Metrics

The **My Plan** page automatically calculates and displays:

* Total exercises
* Total workout minutes
* Total calories

The metrics update whenever workouts are added or removed.

### 5. 💾 Saved & Daily Workout Management

Manage your planned workouts by viewing today's plan, removing exercises, and marking completed workouts as done. Your plan is stored locally so it can remain available when you return to the application.

## 📁 Project Overview

FitLog is designed to provide a simple and focused fitness experience where users can discover workouts, check exercise details, and organize their daily training plan from one place.

---

### 💻 Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```
